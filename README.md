# 成績帳本

學生個人用的成績追蹤前端原型，可記錄模擬考、期中考、段考、小考與練習卷，並用折線圖和能力多邊形圖觀察自己的分數走向。

## 使用方式

直接用瀏覽器開啟 `index.html`。目前先聚焦個人使用的前端畫面與互動，內建範例資料可直接觀看。

```text
index.html          畫面結構
styles.css          介面樣式
scripts/app.js      前端互動、圖表與範例資料
```

## 目前功能

- 個人暱稱、日期、考試類型、科目、分數、滿分與備註記錄
- 顯示/輸入分頁，讓看趨勢和記分數分開
- 國、英、數、歷、地、公、物、化、生、地科
- 國中小常見合科：社會、理化、自然
- 折線趨勢圖，可依科目、考試類型篩選
- 趨勢科目可選「只看原始科目」或「包含合科/分科」
- 能力圖可切換合併五軸：國文、英文、數學、社會、自然
- 能力圖可切換拆分細科：國文、英文、數學、歷史、地理、公民、物理、化學、生物、地科
- 六種前端風格：柔和粉、柔和藍、柔和黃、柔和綠、暗黑科技、簡潔
- 個人近況卡與文字摘要
- CSV 匯出與匯入收在設定區

## 後續可擴充
